This section applies machine learning classification techniques to predict passenger survival.

Activities performed

* Loaded and inspected the Titanic dataset.
* Identified and handled missing values.
* Selected relevant features, including passenger class, gender, age, fare and embarkation point.
* Converted categorical variables into numerical values.
* Explored survival rates by gender and passenger class.
* Created correlation visualizations.
* Split the dataset into training and testing sets.
* Developed Logistic Regression and Random Forest classification models.
* Evaluated model performance using accuracy, confusion matrices and classification reports.

Objective: To understand how passenger characteristics relate to survival and compare the performance of two classification algorithms.
